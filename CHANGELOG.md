# Changelog

Notable changes to Atomic Helper are recorded here. Release assets and generated release notes are available on [GitHub Releases](https://github.com/VeyroDeveloper/atomic-helper/releases).

## [0.3.6] - 2026-11-05

- Added a safe-cleanup action for rpm-ostree metadata, unused Flatpak runtimes, and old journal entries.
- Added support bundle export with system details, recent journal entries, failed services, and installed package names. Review the archive before sharing it because logs can contain personal information.
- Added quick links to Fedora Silverblue documentation, Flathub, and RPM Fusion.
- Added a system diagnostics summary for troubleshooting.

## [0.3.5] - 2026-11-04

- Mini update to verify the in-app update flow end-to-end.
- Added a clearer update-confirmation prompt before downloading the new AppImage.

## [0.3.4] - 2026-11-04

- Added a confirmation popup when an app update is available.
- Included the report and update-helper enhancements in packaged AppImages.

## [0.3.2] - 2026-11-04

- Added an About-screen indicator explaining whether the current launch supports in-app AppImage updates.
- Published the v0.3.2 x86_64 AppImage release.

## [0.3.1] - 2026-11-04

- Published the v0.3.1 x86_64 AppImage release.
- Refreshed project documentation.

## [0.3.0] - 2026-11-01

- Initial published AppImage release.
- Added the Electron desktop application for Fedora Atomic maintenance, setup, and security tasks.
- Added GitHub Releases-based app update checks and AppImage update installation.
