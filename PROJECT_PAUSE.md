# Project pause notice

Atomic Helper is currently paused until December 2026.

This pause is intended to give the project time to reassess its direction, stabilize the existing AppImage workflow, and review the current maintenance and diagnostics features before continuing with new development.

## Why the pause is in place

The project has reached a point where a short break is useful to:

- review the current feature set for reliability and clarity
- assess the long-term architecture and maintenance approach
- ensure the existing Fedora Atomic workflows remain stable for users
- reduce unnecessary churn while preparing the next round of improvements

## What this means for users

- Existing releases remain available for use.
- The current app continues to serve as the active rolling build for now.
- No major new feature work is planned until the pause period ends.
- The next scheduled update window is expected to begin on 1 December 2026.

## Expected next step

The project will resume planned updates and improvements after the review period, with a focus on stability, usability, and a clearer direction for future releases.

This pause is a temporary maintenance step, not a permanent shutdown of the project.
